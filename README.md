“House of Games” is an interactive web-based collection of classic and modern board games, including Tambola (Bingo), Snake & Ladder, Ludo, and the original Gekitai game. Built using HTML, CSS, and JavaScript, this project offers a dynamic and immersive gaming experience, complete with animated cyberpunk-style UI, responsive dashboards, timers, AI opponents, and multiplayer support.

Players can enjoy a realistic digital board game experience with highlighted valid moves, strategic gameplay rules, and engaging animations, making it feel like the offline version of these games but with added digital enhancements and interactive features.

Tech Stack: HTML | CSS | JavaScript | DOM Manipulation | Animation | AI Logic
